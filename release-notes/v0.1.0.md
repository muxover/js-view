# JS-View v0.1.0 — Real-browser pages for agents

**Release date:** 2026-10-03

### Install

```bash
npm install @muxover/js-view@0.1.0
```

---

## Summary

First release. JS-View loads a page in headless Chromium, runs its JavaScript, and hands agents what actually rendered as clean markdown. It installs as a plugin in Claude Code, Codex, and Cursor, runs as a CLI, and self-hosts as an HTTP service.

---

## What's included

### MCP server

- `render`, `screenshot`, `links`, and `network` tools over stdio
- Scroll, click, fill inputs, and wait for selectors before reading
- Bot checks, login walls, HTTP errors, and empty pages reported with hints
- `selector` and `max_chars` to keep results small; 30,000 characters by default

### Agent installs

- Claude Code, Codex, and Cursor plugins from `muxover/js-view`
- One-click Cursor MCP install
- `npx skills add muxover/js-view` for any other agent

### CLI

- `npx @muxover/js-view <url>` with `--scroll`, `--click`, `--select`, `--links`, `--network`, and `--screenshot`
- `js-view login` signs in once in a visible browser and saves the session
- `js-view install` downloads Chromium; an installed Chrome or Edge works without it

### HTTP service

- `POST /render` with a browser pool, API-key auth, rate limiting, and a private-host guard
- Redis-backed workers and a Docker image
